快速入门

CalculatorX 使用手册

欢迎使用 CalculatorX 计算器（简称 CalcX）。本指南将带你快速熟悉软件的核心布局与基础操作，助你立刻上手这款功能强大的科学计算器。

简介

CalcX 是一款 专业级符号计算器 (CAS) 兼 多功能计算工具，你可以借助它轻松应对微积分、方程求解、符号推导、函数图像、概率统计等诸多场景。也能作为计算、单位转换等日常工具。

界面

初次打开应用，所有的布局逻辑都旨在为你提供最沉浸的计算体验：

  • 公式显示区： 告别枯燥的纯文本代码。你的所有输入与计算结果，都会被实时渲染为印刷级的标准数学公式。
  • 主键盘区： 提供大面积的数字与基础运算符，支持极速连击输入，并具备防误触设计。
  • 高级功能面板： 包含三角函数（支持 DEG/RAD 极速无缝切换）、指数对数、微积分符号及各类科学常数。
  • 历史记录抽屉： 每次按下等号，完整的计算过程都会被自动存档。你可以随时查阅，甚至点击历史结果将其直接“无缝填入”当前的光标位置。
