常见问题解答

1. 什么是“符号计算器”？

符号计算器 = 能“推导公式”的数学神器

  • 核心：普通计算器算数字（如 1+1=21+1=21+1=2），符号计算器算符号（如： x2−1=(x−1)(x+1)x²-1=(x-1)(x+1)x2−1=(x−1)(x+1) ）。
  • 主要功能：能做因式分解、求导数、解方程，且给出精确答案（保留根号或分数），而不是小数近似值。

2. 什么是 LaTeX\LaTeXLATE​X？

LaTeX\LaTeXLATE​X (LaTeX) 是数学公式的“国际标准写法”。

  • 核心作用：用纯文本代码（如 \frac{a}{b}）就能排出印刷级的高质量公式。
  • 最大优势：排出的公式极其漂亮、专业，且复杂结构（矩阵、多行方程组）也能轻松处理。
  • 常用场景：写论文、出试卷、做学术报告时用它来输入公式。

除此之外，LaTeX\LaTeXLATE​X 被广泛用于编写书籍、期刊、论文等，是科研的重要写作工具。

3. 计算结果为什么总是显示分数或根号，而不是小数？

这是因为 CalculatorX 默认处于精确计算模式（Exact Mode）。

  • 精确模式：保留数学上的绝对精准度（例如输出 2\sqrt{2}2​ 而不是1.41421.41421.4142）。这对于工程推导、物理计算和学术作业至关重要。
  • 切换方式：打开侧边栏，点击“设置” -> “答案输出”，即可切换“自动模式”与“小数模式”，自动模式会自动判断当前是否需要以精确模式输出。
  • 临时切换：点击键盘上的S⇄D按钮，即可直接在“自动模式”与“小数模式”之间临时切换。长按S⇄D按钮，会弹出更多可切换的菜单，包含： 小数、分数、带分数、度分秒。

4. 需要联网吗？

主要功能完全不联网，仅部分功能需要，例如：联网获取汇率等。

所有的符号推导、极限求解和矩阵运算都在设备本地实时完成。所有计算过程和历史记录 100% 留在本地，CalculatorX 承诺不收集任何个人数据，非必要不联网。
