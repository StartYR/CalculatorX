## 变更摘要

进制转换入口新增程序员整数与 IEEE 754 页面。整数支持 8/16/32/64 bit、四进制同步、算术表达式、逻辑与算术移位、旋转/带进位旋转、ADC/SBB、三态标志、逐 bit 编辑和原码/反码/补码观察。IEEE 支持 binary16/32/64、精确 roundTiesToEven、特殊值、字段和 NaN payload 观察。

五列键盘复用 `KeyboardKeySurface`，API 26 且全局开关开启时使用底部 TabBar 的沉浸光感，其他情况使用传统布局。原生长按菜单提供副功能，支持连续退格、复制与粘贴、触感和撤销/重做。

偏好保存最近配置；模块往返保持进程内会话。成功确认的计算写入既有 RDB，支持完整上下文回填。程序员去重会比较扩展配置；同时校正全局历史实际页签和分类索引，使“转换”能够显示 `base` 记录，表结构无需迁移。

## 实现边界

- 整数核心使用 bit 数组，不以 `number` 保存完整 64 位数据，也不进入 CAS/WebView。
- 负字面量不能小于补码最小值；正字面量可输入无符号位模式，再按当前符号解释。
- 乘除/逻辑运算 CF、OF 不适用；旋转只定义 CF；C-in 手动控制，固定语义不模拟 CPU。
- IEEE 显示十进制为简短表示，精确值另以整数乘二进制幂展示。格式转换直接从位模式舍入；跨格式 NaN 规范化，原始位编辑保留 payload。
- 普通数值转换和处理器专属行为不在本版范围。浮点四则运算已在 2026-09-28 后续更新中加入；版本号和 Changelog 未变更。
- 使用计划中保存的信息层级实现排版，截图原文件在实施时不可访问。

## 2026-09-28 注释、IEEE 四则运算与实时预览

- 为 `8ae7728` 起新增的 8 个 ArkTS 文件与 2 个测试脚本补充合理注释，独立提交仅新增注释，未修改可执行代码。后续实现按同一规范维护文件头、数学边界与状态契约说明。
- 十进制 IEEE 模式支持加减乘除、科学记数法与粘贴括号；binary16/32/64 的字面量和每一步运算都按目标格式 roundTiesToEven 舍入。
- 处理带符号零、无穷、NaN、溢出和非正规数。参与四则运算的 NaN 与无效运算产生规范 quiet NaN；不提供异常标志或可选舍入模式。HEX/BIN 继续作为原始位模式输入，禁用算术按键。
- 有效草稿实时更新 DEC/HEX/BIN、分类与字段；未完成或无效输入保留最近有效预览。提示文案通过应用资源引用，键盘布局、长条按键和双渲染路径沿用现有实现。
- 浮点粘贴先预览，按 `=` 才写入历史。预览与已确认位模式分离，不覆盖确认的 NaN payload；快照携带预览状态，历史仍以确认位模式恢复，无数据库迁移。
- 核心回归通过 **259,706 项断言**，包含随机浮点运算对照、逐节点舍入、负零、特殊值、预览与历史隔离、输入错误和快照恢复。
- 模块 CodeLinter、`git diff --check`、CLI 静态自测、键盘双渲染架构检查通过。`entry:default@CompileArkTS` 与依赖的资源编译通过；有异常传播提示和既有弃用/权限警告。
