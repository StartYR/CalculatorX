# 半模态标题栏、货币搜索与侧边栏沉浸光感优化

- 状态：已完成，准备合并；API 23 与其他设备形态的真机验证待后续执行
- 类型：功能、修复、样式优化
- 分支：`feature/api-update-26-2`
- 完成日期：2026-09-19

## 变更摘要

本分支继续完成 API 26 沉浸光感迁移中暂缓的高价值界面：重构历史记录 Sheet 标题栏，为货币选择搜索框和两个半模态标题栏接入适合其层级的材质，并只对侧边栏顶部标题栏启用自适应沉浸光感。

历史记录按日期分组的吸顶位置也同步修正。分组标题现在停留在实际标题栏下方，不再进入标题栏背后的模糊区域；半模态历史与全局历史分别使用与各自标题栏高度匹配的起始偏移。

本次没有材质化整个侧边栏，也没有处理图形编辑全屏 Sheet。此前验证表明，普通计算按键位于 ArkUI 沉浸光感不支持的普通内容区域，因此未将按键材质实验带入本分支。

## 用户可见行为

- 半模态历史记录使用 HDS `MODAL` 标题栏、滚动渐变模糊和自适应系统材质。
- “全局历史记录”和“清空”进入历史标题栏右侧菜单；当前分类没有记录时不显示清空操作。
- 历史记录帮助按钮回到标题右侧，保持较小尺寸，不与高频主操作并列。
- 货币选择页的搜索框进入标题栏底部区域，并在 API 26 使用 `THIN` 沉浸光感材质。
- 搜索框外层保留足够的底部空间，材质阴影不再被标题栏与内容区交界裁剪。
- 货币选择与历史记录标题栏均使用自适应材质和滚动渐变模糊，标题文字在原始态和滚动态保持系统主文字色。
- 侧边栏顶部标题栏使用自适应沉浸光感；“全局历史记录”和“设置”继续作为标题栏菜单操作，列表主体保持原背景与滚动方式。
- 侧边栏 `CalcX` 标志和列表顶部间距经过调整，标题区与内容区的视觉节奏更紧凑。
- 半模态历史和全局历史的日期分组标题吸附在各自标题栏下方，滚动时不再被标题栏模糊遮挡。

## 设计与实现

### 历史记录 Sheet

`HistorySheet.ets` 以 `HdsNavigation` 作为内容容器，并使用自定义 `stackBuilder` 保留“历史记录”标题与帮助按钮。标题栏菜单由当前数据状态动态生成：全局历史入口始终存在，清空操作只在当前分类存在记录时加入。

标题栏使用以下组合：

- `HdsNavigationTitleMode.MODAL`；
- `ScrollEffectType.IMMERSIVE_GRADIENT_BLUR`；
- `hdsMaterial.MaterialType.ADAPTIVE`；
- `hdsMaterial.MaterialLevel.ADAPTIVE`；
- 原始态与滚动态均显式指定主标题和菜单图标颜色。

帮助弹窗和清空确认弹窗继续使用 `ULTRA_THICK` 对话框材质；本分支只重构入口位置和标题栏层级，没有改变历史记录的插入、删除与清空语义。

### 货币选择

`CurrencySelector.ets` 将搜索框放入 HDS 标题栏的 `bottomBuilder`，标题和搜索区域作为同一个顶部层级参与滚动模糊。搜索框使用独立的 `CurrencySearchVisualModifier`：

- API 26 直接应用 `createSearchMaterial()` 返回的 `THIN` 材质；
- API 23 至 API 25 保留透明背景、细边框和 `BlurStyle.Thin` 降级样式；
- API 26 专属调用仍位于直接、正向的 `deviceInfo.apiAvailable('26.0.0')` 分支中。

搜索区域的左右、上下内边距与标题栏底部高度配合，既保留输入焦点和键盘避让行为，也为系统材质阴影提供完整绘制空间。

### 侧边栏标题栏

`SideBarMenu.ets` 在原有侧边栏内部使用 HDS `MODAL` 标题栏。`CalcX` 标志由自定义标题 Builder 渲染，历史记录和设置继续使用带稳定 Semantic ID 的标题栏菜单项。

沉浸光感只应用于顶部标题栏：列表、分组、底部帮助入口、关闭遮罩、圆角与侧边栏整体阴影保持原实现。这样能在高频可见区域获得材质反馈，同时避免给长列表和整个侧边栏增加不必要的持续渲染负担。

### 历史分组吸顶

`UniversalHistoryList.ets` 使用 `contentStartOffset` 为吸顶分组标题保留标题栏空间：

- 全局历史使用 81vp；
- 半模态历史使用调用方提供的 `topContentPadding`，当前为 56vp。

列表继续使用 `StickyStyle.Header`。分组标题本身保持透明背景和现有字体层级，只调整顶部占位与标题内边距，不改变历史数据的分组逻辑。

### 材质工具

`ImmersiveMaterialUtils.ets` 新增搜索框专用 `createSearchMaterial()`，并补全各材质工厂的中文职责与兼容性注释。Sheet、弹窗、菜单、搜索框和 TopBar 分别保留独立工厂，避免用一个材质参数覆盖不同界面层级。

## 兼容性与边界

- 目标 API 继续为 `26.0.0`，最低兼容 API 继续为 `6.1.0(23)`。
- API 26 搜索框使用 `THIN` 系统材质；旧系统走原模糊、边框和透明背景路径。
- HDS 标题栏使用自适应材质等级，由系统结合主题、设备能力和用户设置决定最终表现。
- 历史记录的数据查询、插入、删除、清空和全局页面跳转行为没有改变。
- 货币筛选、字母索引、焦点动画和键盘避让行为没有改变。
- 侧边栏列表、全屏关闭遮罩、整体阴影和开合手势没有材质化。
- 图形编辑全屏 Sheet 继续保持现状，不在本分支增加材质负载。
- 普通计算按键未接入系统沉浸光感；其所在普通内容区域不属于当前 API 26 的有效范围。
