## 行为

- 数值模式始终显示键盘。
- 整数展开“位 / 编码”或 IEEE 展开“字段”时，键盘向下滑出；再次点击当前面板按钮关闭面板时，键盘向上滑回。
- 位和编码之间切换时保持收起。切换模式会结束当前检查面板并保留各自输入；帮助使用独立弹窗，打开或关闭均不影响面板和键盘状态。
- 收起后底部显示上方 `△`、下方 `⌨` 的双行唤起按钮，点击关闭检查面板并升起键盘。API 26 使用 TopBar 光感材质与局部 TabBar，低版本回退普通背景。
- 键盘保持挂载完成位移动画；隐藏时禁用触摸与无障碍遍历。唤起按钮位于键盘下层，下滑前挂载，上滑完成后卸载；动画完成回调通过序号校验，避免快速切换时旧回调提前移除按钮。升起过程中按钮禁用触摸与无障碍遍历。
- 滚动内容底部留白随键盘状态过渡；收起时预留唤起按钮、导航区域与额外间距，按钮容器另有阴影留白。

## 参数与定位

`BaseConverter.ets` 的 `BASE_KEYBOARD_SLIDE_DURATION` 控制升降时长（280 ms），`BASE_KEYBOARD_RESTORE_HEIGHT` 控制唤起按钮高度（48 vp）。`restoreButtonBottom()` 决定按钮底距，`contentBottomInset()` 决定内容底部安全区。

debug 语义状态新增 `panel`、`keyboardHidden`；`base.keyboard.show` 是唤起按钮的稳定 ID。
