## 用户可见行为

- 标签顺序为“数值”“整数”“IEEE 754”，新会话默认数值模式，已有偏好和历史仍恢复原标签；三个标签独立保留输入。
- HEX / DEC / OCT / BIN 支持正负数和有限小数，不限制为 64 bit；输入最多 256 字符。
- 数值模式移除顶部表达式栏，在当前进制行直接显示输入。IEEE 格式使用下拉菜单。
- 三种模式的 BIN 每行固定分组 32 个二进制数字，窄屏缩放字形；末行不足 32 位不补零，长按复制完整文本。
- 数值右对齐；其他进制自动换行；小数最多显示 16 / 32 / 64 / 128 位，超出部分以 `≈` 和省略号标记。
- 切换进制与显示精度使用精确原值；“编辑原值”返回来源进制，避免编辑截断结果时静默损失精度。
- 五行四列专属键盘支持小数点、变号、连续退格和清空，不提供等号，复用传统/沉浸光感及低版本回退。
- 支持粘贴预览、长按复制、撤销/重做、偏好保存和已有历史回填；数值页不主动新增历史。

## 实现与兼容

`NumericValue` 使用精确非负整数构造带符号有理数，长除产生显示结果；`NumericSession` 保存原始输入、缓存结果与独立草稿。数值模式不提供算术表达式、指数或进制前缀。

历史 `extra_params` 升至版本 2，保存原始文本及其进制，继续读取版本 1。偏好键、`module_type=base`、历史事件和原有 CLI 字段保留；数据库表结构不变。CLI 增加数值标签与“编辑原值”的精确白名单项，未重建启动器。

## 验证

- 数值宿主测试：5,982 项断言通过，包含随机四进制小数长除对照、超过 64 位整数、256 字符边界、模式隔离、精确往返、历史与旧配置兼容。
- 既有程序员宿主测试：259,706 项断言通过。
- ArkTS 本地测试：16 项通过，0 failure / error，含 5 项数值测试，覆盖默认模式与二进制分行。
- debug `assembleHap` 构建、模块 CodeLinter、键盘架构、CLI 静态检查和差异空白检查通过。
- 构建仍有工程 API 弃用与异常传播告警。未安装到设备，未执行 UI 场景或 API 23 / API 26 真机验收。

新增“数值”进制换算，支持大整数、正负数和小数，提供精确原值保留、近似显示标记、显示位数选择及历史恢复。
